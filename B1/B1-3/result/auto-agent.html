01 / 반복 업무 정의

자동화할 반복 업무

매일 영문 신디사이저 뉴스 사이트(Synthtopia)를 들어가, 새 기사를 확인하고 → 한국어로 번역·요약하고 → 출처·날짜와 함께 정리해 보관하는 작업.

이 일은 매일 반복되고, 새 글만 추려야 하며, 번역·요약·정리라는 정형화된 단계로 이뤄진다. 사람이 직접 하면 시간이 들고 누락·중복이 생기기 쉬워 자동화에 적합하다.

목표 산출물: 한국어 제목·요약·태그·원문링크·발행일 + AI 생성 썸네일을 한 행으로 저장한 검색 가능한 뉴스 아카이브.

02 / 도구 선정

도구 선정 및 이유 — n8n

여러 자동화 도구를 비교한 뒤 n8n을 선정했다.

비교 항목n8nZapierMake
호스팅셀프호스팅 가능 (NAS/Docker)클라우드 전용클라우드 전용
비용자체 호스팅 시 무료·무제한 실행실행 횟수 과금오퍼레이션 과금

선정 이유

  • 이미 운영 중인 Synology NAS에 셀프호스팅해 실행 비용이 들지 않고 데이터를 내부에 둘 수 있다.
  • OpenRouter·NocoDB 같은 임의 API를 HTTP 노드로, 응답 가공을 Code 노드로 자유롭게 처리할 수 있다.
  • 스케줄 트리거·재시도·실행 로그가 기본 내장되어 안정적 자동화에 유리하다.
03 / 핵심 개념

Trigger · Action · 조건 분기

Trigger (트리거)

워크플로우의 시작을 일으키는 이벤트. 본 프로젝트는 Schedule Trigger를 사용해 매시간 자동 실행한다(시간 기반 트리거).

Action (액션)

트리거 이후 수행되는 실제 작업. 데이터 가져오기(RSS), 외부 API 호출(번역·이미지 생성), 데이터 변환(Code), 저장(NocoDB)이 모두 액션이다.

조건 분기 (Filter / Router)

조건에 따라 흐름을 거르거나 갈래로 나누는 구조. 본 프로젝트에서는 Remove Duplicates가 "이미 처리한 기사인가?"라는 조건으로 흐름을 나눈다 — 신규는 통과, 중복은 폐기. 스케줄 트리거가 매시간 같은 피드를 다시 읽어도 새 글만 하류로 내려보내는 필터다.

05 / 요구사항 충족

공통 요구사항 매핑

요구사항충족구현
Trigger 1개 이상충족 · 1Schedule Trigger (매시간)
Action 2개 이상충족 · 7RSS · 번역 · Parse · 이미지 · Extract · Upload · Save
조건 분기 1개 이상충족 · 1Remove Duplicates (신규/중복)
각 분기 경로 1회 이상 실행확인됨아래 검증 참고
분기 경로 실행 확인: 1차 실행에서 신규 기사 15건이 모두 통과(신규 경로)해 번역·이미지·저장까지 완료. 동일 워크플로를 재실행하면 같은 15건이 중복으로 폐기(중복 경로)되어 하류가 0건 실행 → 두 분기 경로가 모두 실제로 동작함을 확인.
참고: Remove Duplicates는 "필터형" 조건 분기다. 그래프형 분기(IF/Switch)가 추가로 필요하면, 예를 들어 contentSnippet이 비어 있는 기사를 거르는 IF 노드를 02 뒤에 넣어 명시적 라우팅을 더할 수 있다.
06 / 보너스 — AI 연동 Action

생성형 AI를 Action으로 추가

워크플로우에 생성형 AI(Google Gemini, OpenRouter 경유)를 두 개의 Action으로 연동했다.

① 텍스트 요약·번역 액션 (단계 03)

영문 기사를 입력해 한국어 제목·요약·태그를 JSON으로 생성한다. 요약·분류를 AI가 자동 수행하는 보너스 요건을 충족한다.

POST https://openrouter.ai/api/v1/chat/completions
model: google/gemini-2.5-flash-lite
response_format: { "type": "json_object" }   // 출력 형식 강제
→ { title_kr, summary_kr, tags }

② 이미지 생성 액션 (단계 05)

번역된 제목·태그를 프롬프트로 기사별 썸네일 이미지를 생성한다.

POST https://openrouter.ai/api/v1/chat/completions
model: google/gemini-2.5-flash-image   // Nano Banana
modalities: ["image","text"], aspect_ratio: 16:9
→ base64 PNG
실측 비용: 번역은 기사당 약 $0.00005(212토큰 기준), 이미지는 기사당 수 센트 수준. 조건 분기(Remove Duplicates)가 앞에 있어 신규 기사에만 AI 비용이 발생하도록 설계했다.
07 / 실행 결과 · 검증

결과

  • NocoDB articles 테이블에 15건 적재 — 제목·요약·태그·원문링크·발행일 + 썸네일 첨부 포함.
  • 웹 페이지(synthwire.html)에서 NocoDB API로 기사를 라이브 조회해 갤러리로 표시.
  • 재실행 시 Remove Duplicates가 0건만 통과 → 멱등성(중복 미발생) 검증 완료.

안정성 설계 요약

  • 정기 실행 — Schedule Trigger
  • 재실행 안전성 — Remove Duplicates(guid 기준 멱등성)
  • 자동 복구 — 번역 노드 retryOnFail
  • 자원 제어 — 번역·이미지 노드 배치(5초 간격)로 레이트리밋 방어
  • 실패 격리 — Parse JSON의 try/catch, ?? null 방어 코드
