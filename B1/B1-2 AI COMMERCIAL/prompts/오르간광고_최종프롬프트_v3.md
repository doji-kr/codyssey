# 오르간 광고 — 최종 프롬프트 (v3)

> **v3:** 아이/아빠 등 아동 관련 **전면 폐기**. 한 청년의 **삶 곳곳에 오르간이 함께하는 태피스트리** — 아침 커피, 혼자 연주, 비 오는 날, 친구들과, 결혼식. 인물은 청년 한 명(노화 없음) → 일관성 단순, 정책 이슈 없음. 메시지 "삶의 소리, 우리가 함께한다"가 오르간=평생의 동반자로 직결.

## 셋업
- 모든 파이널은 **같은 Veo Quality · 같은 화면비 · 같은 오르간 레퍼런스 이미지**.
- **청년 초상 1장 먼저 확정** → 각 씬 생성 시 레퍼런스로 첨부(텍스트+이미지 이중 고정).
- 전 샷 슬로우모션 → **60초 기준**.
- 핵심 장치: **오르간이 모든 컷에 등장하는 시각적 상수**. 공간·옷·빛은 바뀌어도 오르간은 늘 거기.

## 조립
- 순서: **S1 → S2 → S3 → S4 → S5 → S6** (정점은 결혼식, 그 뒤 명패→로고).
- 흐름: 아침 의식 → 사적인 애정 → 고요 → 공동체 → 사랑. 모든 컷에 오르간이 상수로.
- 리듬: 움직이는 슬로우 샷 사이에 **오르간 매크로 인서트**(건반·먼지·명패)를 1~2초씩 끼워 숨 고르기(같은 ARRI 룩·슬로우모션). "삶 곳곳의 오르간"을 디테일로도 박음.
- 음악: 솔로 오르간, 단순 멜로디 점층, 결혼식·엔딩에서 회귀.
- 로고는 Nano Banana 2, **한글 카피는 편집기에서 직접 타이핑**(이미지 AI는 한글 깨짐).
