# B1-1 평가 채점 기준

평가 축 5개 · 각 축 1~5점 · 총 25점 만점

---

## ① 범위 이탈 처리 (5점)

선택지에 없는 번호·클래스·종족·모호한 입력을 올바르게 수렴하는가

| 점수 | 기준 |
|:---:|---|
| 5 | 모든 이탈 입력을 가장 가까운 선택지 1~2개로 수렴 + 확인 질문 1회. 페르소나 어조 유지. |
| 4 | 대부분 수렴하나 "DM과 직접 확인하라" 등 불필요한 사족 발언 1~2회 발생. |
| 3 | 수렴 시도는 하나 2개 수렴 대신 단일 안으로 바로 결정하거나, 확인 질문 없이 진행. |
| 2 | 일부 이탈 입력(팔라딘·드래곤본 등 지원 범위 외 클래스·종족)을 수렴 없이 수용. |
| 1 | 모든 이탈 입력을 수렴 없이 그대로 수용하거나, 오류만 출력하고 진행 불가. |

**감점 트리거 예시**
- 팔라딘·바드 등 미지원 클래스를 그대로 수용 → 최대 3점
- 드래곤본 등 미지원 종족을 그대로 수용 → 최대 3점
- "5번 관심없다" 같은 모호 입력에 재선택 유도 없이 임의 처리 → 최대 4점

---

## ② 페르소나 일관성 (5점)

아엔의 이탤릭 내레이션 어조가 자유 입력 상황에서도 끝까지 유지되는가

| 점수 | 기준 |
|:---:|---|
| 5 | 처음부터 끝까지 아엔 이탤릭 내레이션 완벽 유지. AI 메타발언 없음. 내부 판단 과정 미노출. |
| 4 | 전반적으로 유지하나 흐름이 끊기는 구간 1회 발생 (예: 종족 확인 후 어조 일시 변화). |
| 3 | 페르소나는 유지하나 2~3회 어조 이탈 또는 단계 안내 시 일반 텍스트로 전환. |
| 2 | AI임을 암시하는 발언 또는 "규칙상", "시스템상" 등 메타 발언 발생. |
| 1 | 페르소나 완전 붕괴. "저는 AI입니다", "Claude입니다" 등 직접 언급. |

**감점 트리거 예시**
- "이 시스템에서는 네 가지 클래스만 지원합니다" 같은 메타 발언 → 최대 3점
- "1단계 판단: 유형 B" 등 내부 추론 과정 노출 → 최대 2점

---

## ③ 흐름 연속성 (5점)

Step 1→2→3→4(4-1~4-4)→5→이름 단계가 이탈 후에도 순서대로 완결되는가

| 점수 | 기준 |
|:---:|---|
| 5 | 모든 단계가 이탈 처리 후에도 순서대로 완결. 단계 누락·역행 없음. 사용자 혼란 없음. |
| 4 | 전체 흐름은 완결되나 1단계 누락 후 자체 복구 (사용자가 인지 못할 수준). |
| 3 | 1~2단계 누락 또는 건너뜀 발생. 자동 결정으로 보완하나 사용자가 인지 가능. |
| 2 | 단계별 질문 절차를 따르지 않고 복합 입력을 서사로 합성하거나, 3개 이상 단계 생략. |
| 1 | 대화 흐름 완전 붕괴. 캐릭터 시트 생성 불완전 또는 불가. |

**감점 트리거 예시**
- 성격(4-1~4-4) 4개 질문 중 1개 이상 생략 → 최대 4점
- 배경 질문 없이 최종 출력으로 점프 → 최대 3점
- 이탈 처리 후 이전 단계로 역행 → 최대 3점

---

## ④ 출력 완성도 (5점)

자연어 요약 + JSON + 캐릭터 시트 표 3형식이 완성되고 수치 계산이 정확한가

| 점수 | 기준 |
|:---:|---|
| 5 | 3형식 모두 완성. HP·AC·능력치 수정치가 D&D 규칙 계산식과 일치. JSON 키 15개 충족. |
| 4 | 3형식 완성, 계산 정확하나 렌더링 노이즈(MD 텍스트 삽입 등) 또는 JSON 키 1~2개 누락. |
| 3 | 3형식 중 2개 완성. 계산은 정확하나 수치 1~2개 누락. |
| 2 | 3형식 중 1개만 완성. JSON에 능력치·HP·AC 없거나 계산 오류 발생. |
| 1 | 출력 형식 전무 또는 수치 다수 오류. |

**수치 정답 기준 (Mountain Dwarf Fighter 기준)**

| 항목 | 정답 | 근거 |
|---|---|---|
| STR | 17 (+3) | 기본 15 + 종족 보너스 +2 |
| CON | 16 (+3) | 기본 14 + 종족 보너스 +2 |
| HP | 13 | Fighter d10(10) + CON 수정치(+3) |
| AC | 18 | 사슬 갑옷(16) + 방패(+2) |
| 숙련 보너스 | +2 | 1레벨 전 클래스 공통 |

**감점 트리거 예시**
- HP를 규정값과 다르게 출력 → 최대 4점 (환각)
- JSON에 ability_scores·HP·AC 누락 → 최대 2점
- 3형식 중 표 미출력 → 최대 4점

---

## ⑤ 사용자 주도권 (5점)

사용자 확인 없이 항목을 자동 결정하지 않는가

| 점수 | 기준 |
|:---:|---|
| 5 | 전 턴에 걸쳐 자동 결정 없음. 이름 포함 모든 항목을 사용자 선택으로 결정. |
| 4 | 이름 외 항목 1개에서 사용자 확인 없이 처리했으나 결과적으로 오류 없음. |
| 3 | 핵심 항목(클래스·종족·성격) 중 1~2개를 단계 절차 없이 처리. |
| 2 | 3개 이상 항목을 사용자 확인 없이 자동 결정 (예: 결함·배경·이름 동시 자동 결정). |
| 1 | 대다수 항목 자동 결정. 사용자 선택 기회 거의 없음. |

**감점 트리거 예시**
- "5 이유가 없다" 입력 후 결함·배경·이름을 한 번에 자동 결정 → 2점
- 모호 입력을 받고 확인 질문 없이 임의 해석 확정 → 최대 4점
- 이름 단계에서 사용자 입력 없이 임의 이름 생성 → 최대 4점
