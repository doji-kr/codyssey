# CLAUDE.md

이 파일은 Claude Code가 이 프로젝트에서 작업할 때 따라야 할 지침입니다.

## 프로젝트 개요

흩어진 AI 프롬프트를 한곳에서 관리하는 터미널 기반 콘솔 프로그램입니다.
메뉴 번호를 입력해 기능을 선택하는 방식으로, 프롬프트를 추가/조회/검색/
즐겨찾기할 수 있습니다. 파이썬 기초를 익히기 위한 학습용 과제입니다.

## 핵심 원칙 (반드시 지킬 것)

- 학습용 과제이므로, 코드는 파이썬 기초 문법(변수, 조건문, 반복문, 함수,
  리스트, 딕셔너리) 위주로 작성한다. 초보자가 읽고 이해할 수 있어야 한다.
- 한 함수에 모든 코드를 몰아넣지 않는다. 기능별로 함수를 분리한다.
- 변수명·함수명은 의미가 드러나게 짓고, 주석으로 의도를 설명한다.
- 코드를 짜면 그 의도와 동작 원리를 한국어로 간단히 설명해 준다.
- 한 번에 전부 만들지 말고, 기능 단위로 작게 나눠 진행하며 사용자가
  따라오고 이해할 수 있게 한다. 목적은 사용자가 직접 배우는 것이다.

## 기술 방향

- 언어: Python 3 (표준 라이브러리만 사용)
- 데이터는 리스트와 딕셔너리로 저장한다.
- 모든 입력은 input()으로 한 줄씩 받는다. 프로그램이 항목을 하나씩
  되물어보고 사용자는 답만 입력한다. (파일을 직접 편집하지 않는다)

## 데이터 구조

각 프롬프트는 딕셔너리 하나로 표현한다:
- title: 제목 (문자열)
- content: 내용 (문자열)
- category: 카테고리 (문자열)
- favorite: 즐겨찾기 여부 (True/False, 기본값 False)

프롬프트 여러 개는 이 딕셔너리들을 리스트에 담아 관리한다.

카테고리 예시: 텍스트 생성, 이미지 생성, 영상 생성, 페르소나, 자동화, 기타

## 구현할 기능 (메뉴)

1. 프롬프트 추가 — 제목/내용/카테고리를 입력받는다. 빈 값이면 다시
   입력을 요청한다. 카테고리는 목록에서 고르거나 직접 입력한다.
   즐겨찾기 기본값은 False.
2. 전체 목록 보기 — 번호, 제목, 카테고리, 즐겨찾기 별표(⭐)를 표시한다.
   프롬프트가 없으면 안내 메시지를 출력한다.
3. 카테고리별 조회 — 카테고리를 고르면 해당 카테고리만 출력한다.
   해당 카테고리에 프롬프트가 없으면 안내 메시지를 출력한다.
4. 검색 — 키워드를 입력받아 제목 또는 내용에 포함된 것을 찾는다.
   결과가 없으면 안내 메시지를 출력한다.
5. 상세 보기 — 목록의 번호를 입력하면 제목, 카테고리, 즐겨찾기 여부,
   내용 전체를 표시한다. 잘못된 번호면 안내 메시지를 출력한다.
6. 즐겨찾기 관리 — 번호로 즐겨찾기를 추가/해제하고, 즐겨찾기된
   프롬프트만 모아 볼 수 있다.
0. 종료 — 프로그램을 종료한다.

- 잘못된 메뉴 번호 입력 시 안내 메시지를 출력하고 다시 메뉴를 보여준다.
- 각 기능 수행 후 메뉴로 돌아온다.
- 프로그램 시작 시 기본 프롬프트가 최소 3개 이상 미리 등록되어 있어야 한다.

## 설계 의도 (레퍼런스에서 배운 교훈)

비슷한 도구(pmc)를 직접 써보며 불편했던 점이 있다. 우리 프로그램은
의도적으로 그 반대로, 더 친절하게 만든다.

- 검색: 사용자가 옵션을 외울 필요가 없어야 한다. 메뉴에서 검색을 고르면
  검색어를 되물어보고, 입력한 한 단어를 제목과 내용 양쪽에서 한 번에
  찾는다. (pmc는 옵션을 따로 줘야 했고 제목·내용을 한 번에 못 찾았다)
- 상세 보기: 목록에 표시된 번호를 그대로 입력해서 선택한다. 제목을
  정확히 타이핑할 필요가 없어야 한다. (pmc는 긴 제목을 정확히 쳐야 했고
  보이는 번호로는 선택이 안 됐다)
- 조작 방식: 모든 기능은 메뉴 번호로 선택하고, 필요한 값은 프로그램이
  하나씩 되물어본다. 사용자가 명령어나 옵션을 외우지 않게 한다.

## 데이터 저장 방식 및 브랜치 계획 (중요)

- main 브랜치: 데이터는 리스트+딕셔너리(메모리)에만 저장한다. 프로그램을
  종료하면 초기화되는 것이 정상이며, 이것이 과제의 필수 요구사항이다.
  main 작업 중에는 파일 입출력(open, json 모듈)을 사용하지 않는다.
- "프롬프트 목록" 기능은 별도 브랜치에서 작업한 뒤 main으로 병합한다.
  (과제가 명시적으로 지정한 요구사항)
- JSON 파일 저장/불러오기는 보너스이며, 또 다른 별도 브랜치
  (예: feature/json-save)에서 작업한 뒤 main으로 병합한다.

## Git 작업 규칙

- 기능 하나를 완성할 때마다 의미 있는 단위로 커밋한다.
- 커밋 메시지는 한국어로, 무엇을 했는지 명확하게 작성한다.
- 커밋을 대신 실행하지 말고, 커밋할 시점이 되면 사용자에게 알려준다.
