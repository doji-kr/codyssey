JSON 자동 저장·불러오기 【보너스】

def load_from_file():
    global prompts
    try:
        with open(FILE_NAME, "r", encoding="utf-8") as f:
            prompts = json.load(f)          # 파일 있으면 불러오기
    except FileNotFoundError:
        pass                                  # 없으면 기본 데이터로 시작

def save_to_file():
    with open(FILE_NAME, "w", encoding="utf-8") as f:
        json.dump(prompts, f, ensure_ascii=False, indent=2)

4. 브랜치 전략

main ●─────────────────────────────────────────────────► 기본 기능 (메모리) │ ├──► feature/json-save ──────────► merge JSON 저장·불러오기 │ ├──► feature/make-markdown ──────────► merge 마크다운 내보내기 │ └──► feature/tui ──────────► merge rich 터미널 UI

main 브랜치 원칙

  • 데이터는 메모리(리스트+딕셔너리)만 사용
  • 종료 시 초기화 — 과제 필수 요구사항
  • 파일 입출력(open, json) 코드 없음

보너스 브랜치 분리 이유

  • 기능 단위 커밋으로 이력 추적 가능
  • main 안정성 유지하면서 실험 가능
  • checkout·merge 사용 기록 남김

5. 설계 의도 — 기존 도구 대비 개선점

항목 기존 CLI 도구(pmc) 이 프로그램
검색 방식 옵션 플래그를 외워야 함.
제목·내용 따로 검색.		 메뉴에서 선택 → 검색어 입력만.
제목·내용·카테고리 한 번에 탐색.
상세 보기 선택 긴 제목을 정확히 타이핑해야 선택 가능. 화면에 보이는 번호를 그대로 입력.
조작 방식 명령어·옵션 조합을 암기해야 함. 모든 기능은 메뉴 번호로만 접근.
프로그램이 필요한 값을 하나씩 되물음.
카테고리 검색 카테고리 필드 검색 불가. "텍스트"만 검색해도 카테고리 "텍스트 생성" 항목이 나옴.
